# Codelab 06 content map

**Progression:** Run a simple Digital ID → register local image asset in pubspec → trace Dart/widget tree → investigate widget API → browse Widget Gallery → research a package at pub.dev → press the star FAB for a short locally bundled audio chime → independent discovery.

| Step | Duration | Interactive learning evidence |
| --- | ---: | --- |
| 01 | 5 | Destination screen preview (Digital ID + star FAB) |
| 02 | 14 | VS Code/CLI creation modes, local-first Flutter code, image asset |
| 03 | 13 | File explorer incl. assets, real pubspec hotspots, quiz |
| 04 | 10 | Clickable widget tree including Column, CircleAvatar, FAB |
| 05 | 12 | Official docs navigator incl. pub.dev, API class anatomy |
| 06 | 12 | Widget Gallery category filters and category quiz |
| 07 | 20 | pub.dev research, audioplayers install, audio asset registration, star-button challenge, reveal code |
| 08 | 4 | Three widget discovery report and exit reflection |

**Gists:** Only `widget_tree` and `text_api` are DartPad-compatible (self-contained). The two local-asset source samples are visible and synchronized but not published as Gists.

**Not taught:** Full widget layout design, state management, counters, SnackBar, backend/API calls, advanced app architecture.
